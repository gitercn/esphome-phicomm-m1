# 斐讯 M1 — 硬件扩展指南



## 1. 核心结论：加装模块一律接在 ESPHome 模块上，不接 SAMD20

| 对比项 | ESPHome 模块（RTL8710BN） | SAMD20 |
|---|---|---|
| 固件 | 开源，YAML 直接改 | Phicomm 私有，封闭 |
| 空闲 IO | 有（见 §2） | 几乎全被占用（传感器/屏幕/按键/RTC/CHIP_EN） |
| 网络能力 | WiFi + ESPHome 生态 | 无 |
| 扩展成本 | 加一行 YAML | 需提取固件、逆向、重新开发 Cortex-M0+ |

- SAMD20 现有负载：PMS7003（PM2.5）、ZE08-CH2O（甲醛）、SHT30（温湿度）、TM1680（数码管）、
  物理按键、RTC、PA24 控制模块 CHIP_EN。
- 新传感器数据与 M1 原有传感器（经 UART 上报）在 **Home Assistant 里合流**，互不干扰。

## 2. RTL8710BN 引脚清单（占用 vs 空闲）


### 2.1 已占用（不要动）

| 模块引脚 | GPIO | 用途 |
|---|---|---|
| 9 | PA23 | UART0 TX → SAMD20（应用 UART，命令 0x02/0x03/0x16） |
| 10 | PA18 | UART0 RX ← SAMD20（数据 0x01/0x0c/0x0f/0x18） |
| 14 | PA5 | TP53 = WiFi 图标灯（常亮=已连网） |
| 13 | PA12 | TP54 = 红叉灯（亮=WiFi 断开） |
| 24 / 25 | PA30 / PA29 | 日志/下载 UART（TTL 刷机口）——当前被日志占用 |
| 1–4 | PA14 / PA15 | SWD 调试口（TP15/TP14）——保留 |
| 11 | — | CHIP_EN，由 SAMD20 PA24 控制，勿动 |

### 2.2 空闲可用

| 模块引脚 | GPIO | 复用功能 | 扩展建议 |
|---|---|---|---|
| **12** | **PA0** | PWM3 | **红外发射（38kHz 载波）**、继电器、PWM、呼吸灯 |
| **23** | **PA8** | EASYLINK | **GPIO 输入**：红外接收、盖格脉冲计数、按键 |
| **8** | **PA19** | UART0_CTS / **ADC1 (A0)** | **模拟量采集**（MQ 气体传感器、光敏、麦克风包络）、通用 GPIO/输入、软件 UART RX |
| **7** | **PA22** | UART0_RTS | 通用 GPIO/输出，或软件 UART TX |
| **19** | **PA11** | BOOT strap | **仅可做输出**（继电器）。⚠️ 上电拉低会进下载模式，**禁止作输入** |

### 2.3 可释放的引脚（需权衡）

| 模块引脚 | GPIO | 当前用途 | 释放后用途 | 代价 |
|---|---|---|---|---|
| 24 / 25 | PA30 / PA29 | 日志/刷机口 | 第二路硬件 UART（如 MH-Z19） | 失去串口日志/串口刷机，改走 OTA/API |

> 说明：RTL8710B 的硬件 UART 复用有限（UART0 TX=PA23/PA4、RX=PA18/PA1；UART2=PA30/PA29）。
> 若需要第二路 UART，释放 PA29/PA30 是**硬件 UART2** 方案；但 ESPHome 的 libretiny UART
> 组件在引脚不匹配时**自动降级为 SoftwareSerial**，因此 PA19(RX)/PA22(TX) 可组成**软件 UART**
> （9600 波特率稳定），**不需要牺牲日志口**——低速串口传感器（MH-Z19、LD2410、SU-03T、
> PMSA003、O₂ 模块等默认 9600）优先走这条。仅当需要 ≥38400 波特率时才释放 PA29/PA30。

## 3. 各类加装模块的接线与 ESPHome 方案

### 3.1 红外遥控（控制空调 / 电视 / 净化器）✅ 最推荐
- 发射：PA0（PWM3）+ 三极管驱动红外 LED → `remote_transmitter`，空调用 `climate` 组件
- 接收（学码）：PA8 → `remote_receiver`
- 联动：M1 温湿度 / 空气质量触发 HA 自动化 → 发空调/净化器指令

### 3.2 O₂ 、CO₂ 传感器（MH-Z19 / SCD40 / 电化学 O₂）✅
- **MH-Z19**（UART 型 CO₂）：优先走**软件 UART**（PA19 RX，9600）→ `mhz19` 组件；也可释放 PA29/PA30 硬件 UART2
- **SCD40/SCD41**（I2C 型 CO₂）：PA0（SDA）+ PA8（SCL）软件 I2C → `scd4x` 组件
- **电化学 O₂ 传感器**（如 ME2-O2 系列）：输出毫伏级模拟信号，需运放调理后接 **PA19 ADC**（见 §3.6）；更省事的做法是买带 **UART 输出（9600）** 的成品 O₂ 模块，走软件 UART
- 注意供电：MH-Z19 需 5V，SCD4x 需 3.3V/5V，模块侧确认有对应电源

### 3.3 麦克风 / 语音识别 ⚠️ 不接 RTL8710BN 本地识别
- RTL8710BN 算力不足以跑本地唤醒词/ASR
- 方案 A：Home Assistant 侧接 ESP32 语音助手板，M1 只做传感器/执行器
- 方案 B：离线语音模块（如 SU-03T）UART 输出 → 接模块 PA29/PA30，识别结果上报 HA

### 3.4 盖格计数器 ✅
- 盖格管模块输出脉冲 → PA8（GPIO 输入），`pulse_counter` 计 CPM，换算 µSv/h
- 若模块带 UART 输出 → 走第二路 UART

### 3.5 联动空气净化器 ✅
- 红外遥控型 → 复用 §3.1 红外发射
- 米家/智能型 → **HA 直接集成**，用 M1 的 PM2.5/CO₂ 传感器触发自动化（零硬件，最推荐）
- 普通型 → PA0 驱动继电器控制电源（注意：断电重启净化器不一定自动开机）

## 3.6 模拟量气体传感器（MQ 系列 + PA19 ADC）✅ 低成本定性监测

> **重要发现**：RTL8710BN 的 **PA19 就是 ADC1（Arduino A0）**，ESPHome 有官方 `adc` 组件
> （`adc_sensor_libretiny`），无需额外硬件就能采集模拟量气体传感器。

- 适用传感器一览：

  | 传感器 | 目标气体 | 典型场景 | 备注 |
  |---|---|---|---|
  | MQ-2 | 可燃气体 / 烟雾 | 烟雾报警 | 通用，最便宜 |
  | MQ-4 / MQ-5 | 天然气 / 甲烷 | **燃气泄漏** | 燃气报警首选 |
  | MQ-6 | 液化气 LPG | **燃气泄漏** | 厨房 |
  | MQ-7 | 一氧化碳 CO | 煤气/汽车尾气 | 需 PWM 脉动加热（PA0 输出 5V 方波） |
  | MQ-131 | 臭氧 O₃ | 空气净化器旁 | 加热电压高，需外置电源 |
  | MQ-135 | TVOC / 氨 / 硫化物 | 空气质量 | 便宜但定性 |
  | 电化学 O₂ 模块 | 氧气 O₂ | 密闭空间/新风机 | 毫伏级输出，需运放或买带 UART 的成品 |

- ⚠️ 限制与安全：
  - MQ 系列**精度低、有预热漂移**，适合做"超标报警 / 趋势"，不适合精确 ppm 计量。
  - **燃气/CO 安全用途务必采用认证商用探测器**（如报批的燃气报警器），DIY MQ 仅作辅助参考，避免误报漏报。
  - 若 MQ 模块带 DO 输出，用 PA8 读数字电平最可靠（省去 ADC 标定）。

## 3.7 数字 TVOC / eCO₂ / AQI 传感器（I2C）✅ 推荐

与 M1 已有传感器（甲醛/PM2.5/温湿度）互补，构成完整室内空气质量（IAQ）面板。全部走**软件 I2C**（PA0=SDA、PA8=SCL，多设备可并联，ESPHome `i2c` 组件支持任意引脚）：

| 传感器 | 输出 | ESPHome 组件 | 备注 |
|---|---|---|---|
| SGP40 | VOC 指数 | `sgp4x` | 需湿度补偿（可直接用 M1 SHT30 数据） |
| SGP41 | VOC + NOx | `sgp4x` | 带 NOx（油烟/燃气） |
| SGP30 | eCO₂ + TVOC | `sgp30` | 经典款，需长期运行校准 |
| CCS811 | eCO₂ + TVOC | `ccs811` | 基线漂移需定期校准 |
| ENS160 | eCO₂ + TVOC + AQI | `ens160` | 数字输出，推荐 |
| SFA30 | 甲醛（数字） | `sfa30` | 与 M1 内置 ZE08-CH2O 交叉验证，免校准 |


## 3.8 毫米波人体存在 / 距离（LD2410）✅ 智能联动

- **LD2410**（UART，默认 9600）输出人体存在、微动、运动距离/能量。
- 接线：LD2410 **TX → PA19（软件 UART RX）**、VCC=5V、GND 共地；若用 LD2450（多目标），可改用 PA29/PA30 硬件 UART2（波特率 115200）。
- YAML：`uart: rx_pin: PA19 baud_rate: 9600` → `ld2410` 组件（ESPHome 内置）。
- 联动：**有人亮屏**（M1 屏幕自动点亮）、**无人熄屏**；或作为离家/在家自动化触发、联动空调/灯光。

## 3.9 环境与安全补充传感器

| 传感器 | 类型 | 接入方式 | ESPHome 组件 | 典型用途 |
|---|---|---|---|---|
| BH1750 光照 | I2C | PA0/PA8 软件 I2C | `bh1750` | 联动 M1 屏幕亮度/夜间模式 |
| BMP280 / BME280 气压 | I2C | 同上 | `bme280` | 气压/海拔 |
| BME680 | I2C | 同上 | `bme680` | 温湿度+气压+VOC 气体指数 |
| 紫外线 UV（GUVA-S12SD） | 模拟 | PA19 ADC（需运放） | `adc` | 户外空气箱 |
| 噪音包络（MAX4466/MAX9814） | 模拟 | PA19 ADC + RMS 计算 | `adc` + `template` | 粗略声级（实验性） |
| 水浸 / 漏水 | 干接点 | PA8 `binary_sensor` | `binary_sensor` | 空调/加湿器旁漏水报警 |
| 门窗磁 / PIR 人体 | 干接点 | PA8 `binary_sensor` | `binary_sensor` | 安防联动、人来自动亮屏 |

- 模拟类共用 PA19：UV、噪音包络、MQ 气体**三选一**（同一时间只能接一路 ADC 信号）。
- 数字干接点类共用 PA8：红外接收、盖格脉冲、水浸、门窗磁、PIR **不能直接并联**（干接点/开漏输出无总线仲裁）。同一时间只能接一路，或把不冲突的输入分到 PA19/PA22（PA19 未用作 ADC、PA22 未用作软件 UART TX 时）。

## 3.10 燃气联动执行器（安全场景）

燃气报警（MQ-5/MQ-6 DO → PA8，或认证探测器干接点）触发 HA 自动化后执行：

- **燃气电磁阀**：PA0/PA11 继电器控制（电磁阀一般 12V/220V 驱动，必须继电器隔离，且设计**手动恢复**机制，避免误动作困住用户）。
- **排风扇 / 油烟机**：PA0 继电器控制电源，或红外遥控（§3.1）。
- **HA 告警**：通知 / 电话 / 闪烁灯光（M1 WiFi LED 可做本地告警灯）。

> ⚠️ 燃气切断是**高风险动作**：务必使用认证器件、设置自动/手动恢复策略，并充分测试后再部署。

## 3.11 软件 UART 汇总（不牺牲日志口）

- ESPHome libretiny UART 组件在引脚不匹配硬件 UART 时**自动降级 SoftwareSerial**。
- 第二路串口接线：**PA19 = RX**、**PA22 = TX**（如只需接收传感器数据，只接 RX）。
- **9600 波特率**稳定；38400 以下一般可用；更高波特率建议释放 PA29/PA30 硬件 UART2。
- 适用设备：MH-Z19（9600）、LD2410（9600）、SU-03T（9600）、PMSA003（9600）、O₂ 成品模块（9600）。
- 注意：PA19 同时是 ADC1——**接了串口传感器就不能同时接模拟量传感器**，两者二选一。

## 4. SAMD20 固件提取（仅研究用，扩展不需要）

> 扩展硬件不需要动 SAMD20。以下步骤仅供深入逆向/修改 SAMD20 行为时参考。

1. **定位 SWD**：ATSAMD20G18A（48 脚）的 SWCLK=PA30、SWDIO=PA31，按数据手册确认引脚号后
   在 PCB 上用万用表追线到测试点。
2. **连接**：J-Link / Atmel-ICE / DAPLink，目标 3.3V 供电，`connect` 后 dump 整片 Flash（256KB）。
3. **风险——安全位（Security Bit）**：若出厂熔断了安全位，SWD 会拒绝连接；
   **强行 Chip Erase 会清空固件**。首次连接先尝试读取，读不了即已锁定，勿乱擦。
4. **分析**：Ghidra 以 `ARM:LE:32:Cortex-M0+` 加载，SAMD20 外设寄存器按数据手册建结构体。
5. **意义评估**：UART 协议已基本弄清，SAMD20 内部逻辑（传感器轮询、
   屏幕/按键驱动）已被动掌握，除非要替换 SAMD20 侧的传感器驱动，否则提取价值有限。

## 5. 推荐扩展优先级（性价比排序）

1. **红外发射 + HA 联动净化器**：PA0 + PA8，最实用，配件最便宜
2. **数字 TVOC / AQI 传感器（SGP41 / ENS160）**：软件 I2C 并联，成本低，补全 IAQ 面板
3. **毫米波人体存在（LD2410）**：软件 UART 9600，不占日志口，智能联动体验提升大
4. **O₂ / CO₂**：MH-Z19 走软件 UART（或释放日志口），HA 空气质量面板补全
5. **模拟量气体报警（MQ-5/MQ-6 + PA19 ADC）**：燃气泄漏辅助报警，注意供电与安全声明
6. **盖格计数器**：PA8 脉冲计数，简单可靠
7. **继电器控制普通净化器 / 排风扇**：PA0/PA11 输出
8. **语音识别**：走 HA 侧 ESP32，M1 不参与

> 引脚占用冲突速查：**PA19** 在 ADC（模拟气体/光敏/麦克风）与软件 UART RX（MH-Z19/LD2410）之间**二选一**；
> **PA8** 用于红外接收、盖格脉冲、干接点输入（水浸/门窗磁/PIR），一次只能接一路输入；
> **PA0** 用于红外发射、继电器、PWM，可复用（同一时刻一个功能）。
