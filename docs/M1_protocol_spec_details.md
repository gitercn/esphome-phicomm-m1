# 斐讯悟空 M1 空气检测仪 — UART 协议文档


---

## 1. 硬件架构（关键前提）

M1 是**双芯片**设计：

| 部件 | 型号 | 角色 |
|---|---|---|
| 主控 MCU | Atmel **ATSAMD20G17A**（实际芯片丝印为 ATSAMD20G18A）(Cortex-M0+) | 读所有传感器、驱动数码管、跑业务逻辑 |
| WiFi 模块 | 庆科 **EMW3080BE** = Realtek **RTL8710B** (AmebaZ) | 仅联网协处理器；WiFi 固件跑在这里 |
| PM2.5 | 攀藤 PMS7003M | 接 SAMD20 |
| 甲醛 | 炜盛 ZE08-CH2O | 接 SAMD20 |
| 温湿度 | 盛思锐 SHT30 | 接 SAMD20 |
| 显示驱动 | **TM1680** 数码管驱动 | 接 SAMD20 |

**传感器和数码管都挂在 SAMD20 上，不接 EMW3080。** EMW3080 与 SAMD20 之间用一条
**UART** 通信：SAMD20 把聚合后的传感器数据用 20 字节帧发给 EMW3080，
EMW3080 把命令（亮度、开关、时间）用反向 12 字节帧发给 SAMD20。

> 这意味着：在 EMW3080 上刷开源固件，**必须实现下面这条 UART 协议**才能拿到数据 / 控屏，
> 而 ESPHome 现成的 `pmsx003`/`sht3xd` 组件用不上（那些芯片不在 EMW3080 引脚上）。

## 2. 芯片间 UART 协议（SAMD20 ⇄ EMW3080）

### 2.1 帧结构（通用）
- 帧头 `0x23`（ASCII `#`），帧尾 `0x21`（ASCII `!`）。
- `frame[1]` = 命令字。
- **SAMD20 → EMW3080（上报方向）固定 20 字节。**
- **EMW3080 → SAMD20（命令方向）固定 12 字节。**
- 无 CRC/校验和，仅靠头尾字节定界。

### 2.2 上报帧 cmd=0x01（传感器数据，SAMD20→EMW3080，20 字节）

| 偏移 | 字节 | 含义 | 换算 |
|---|---|---|---|
| 0  | 0x23 | 帧头 `#` | — |
| 1  | 0x01 | 命令：传感器上报 | — |
| 2  | HCHO_hi | 甲醛高字节 | `raw = (b2<<8)\|b3` |
| 3  | HCHO_lo | 甲醛低字节 | 甲醛(mg/m³) = `raw/1000` |
| 4  | ? | 未解析（疑似保留/子类型） | — |
| 5  | TEMP_int | 温度整数 (°C) | `temp_int = b5` |
| 6  | TEMP_frac | 温度小数（百分位 0–99） | 实测：`温度 = b5 + b6/100` |
| 7  | HUMI_int | 湿度整数 (%RH) | `humi_int = b7` |
| 8  | HUMI_frac | 湿度小数（百分位 0–99） | 实测：`湿度 = b7 + b8/100` |
| 9  | PM25_hi | PM2.5 高字节 | `PM2.5(µg/m³) = (b9<<8)\|b10` |
| 10 | PM25_lo | PM2.5 低字节 | — |
| 11–18 | ? | 未解析（疑似 PM1.0/PM10 或保留，8 字节） | — |
| 19 | 0x21 | 帧尾 `!` | — |

> **实测结论（屏幕比对）**：b6/b8 是**百分位**（0–99），真实值 = 整数 + b/100。
> b4、b11–b18 仍未知（原固件不读取这些字节）。

### 2.3 其它上报命令（SAMD20→EMW3080）

| cmd | 说明 |
|---|---|
| 0x0c | **RTC 时间广播**：`[2:3]`年大端、`[4]`月、`[5]`日、`[6]`时、`[7]`分、`[8]`秒；上电即自发一次，之后约每 57s 一帧，收到 0x02/0x03 后也会触发 |
| 0x0f  | **屏幕开/关状态**：`[2]`=0x00 关 / 0x01 开（SAMD20 在物理按键开关屏时发送） |
| 0x04  | SAMD20 在按住物理按键达到十几秒时发送 |
| 0x10  | SAMD20 在按住物理按键达到几十秒时发送 |
| 0x18  | 长时间按住前面板按键（屏幕亮黄灯）时发送的复位事件：计数 >1 触发重启逻辑 |
| 0x17  | 开机启动帧（上电自发，全零载荷；TTL 抓包发现） |
| 0x07  | 错误帧，载荷 ASCII `"errorup"` ×2（上电初期出现，传感器未就绪，正常现象） |

> 实测时序（TTL 抓包）：SAMD20 上电约 7s 即自发 `0x17 → 0x07×2 → 0x0c`；
> 但周期性 0x01 传感器帧只在收到模块的 **0x01 查询**后按查询节奏回应（每 ~5s 轮询一次即可）。

### 2.4 命令帧（EMW3080→SAMD20，12 字节）

| cmd | 含义 | 帧布局 |
|---|---|---|
| 0x02 | **设置屏幕** | `[2]`=亮度 `{0,25,50,75,100}`（档位 0–4 ×25），`[3]`=开关 0/1 |
| 0x03 | **设置 RTC 时间** | `[2:3]`=年（大端，如 2026），`[4]`=月，`[5]`=日，`[6]`=时，`[7]`=分，`[8]`=秒 |
| 0x01 | 查询传感器 | 全零 12 字节 |
| 0x16 | 长按按键事件应答（固定帧） | 固定 `23 16 00 10 14 00 03 10 f1 ff ff 21`，收到 0x18 时回发 |

帧示例：
```
23 01 00 00 00 00 00 00 00 00 00 21   # 0x01 查询传感器
23 02 64 01 00 00 00 00 00 00 00 21   # 0x02 设屏幕：亮度 100、开
23 03 07 EA 0A 0D 17 16 15 00 00 21   # 0x03 设时间：2026-10-13 23:22:21
23 16 00 10 14 00 03 10 F1 FF FF 21   # 0x16 固定应答帧
```

**亮度档位机制（实测定论，"只有 5 档"）：**
- 链路：模块 `0x02` 帧 byte[2] → SAMD20 固件 → TM1680 显示控制命令。
- TM1680 硬件本身支持 16 档 PWM（见 TM1680 数据手册），但该命令由 SAMD20 发出。
- **实测定论（byte[2] 从 5 扫到 250，步进 5）**：屏幕亮度**只在 25/50/75/100 处跳变**，
  其余值全部无效 → 5 档是 **SAMD20 固件限制**，byte[2] 只认 `{0,25,50,75,100}`。
  → 开源固件只需发 `0x02 + 25 的倍数` 即可。

### 2.5 开机握手帧（可选）

模块上电后发一次 `23 02 64 01 00 00 00 00 00 00 00 21`（亮度 100 + 开屏）
可以让屏幕立即点亮。实测：**不发握手帧也不影响传感器数据**——SAMD20 对
`0x01` 查询始终即时应答。如果不需要屏幕控制，可以完全省略握手帧。

## 3. UART 物理层（已确认）

- **波特率 115200，8 数据位，无校验，1 停止位，无流控（115200 8N1）。**

### 3.1 模块引脚 ↔ RTL8710B GPIO 映射

| 模块引脚 | 数据手册功能 | RTL8710B 引脚 | 用途 |
|---|---|---|---|
| **9** | MICO_GPIO_9 / **MICO_UART0_TXD** | **PA23** | **应用 UART TX → SAMD20**（命令 0x02/0x03/0x16） |
| **10** | MICO_GPIO_10 / **MICO_UART0_RXD** | **PA18** | **应用 UART RX ← SAMD20**（数据 0x01/0x0c/0x0f/0x18） |
| 11 | CHIP_EN | — | 模块使能输入，由 SAMD20 控制 |
| 7 | MICO_GPIO_7 / UART0_RTS | PA22 | （M1 未用） |
| 8 | MICO_GPIO_8 / UART0_CTS | PA19 | （M1 未用） |
| 21/24 | MICO_GPIO_21 / 手册名"MICO_UART1_TXD" | **PA30** | **日志/下载 UART TX**（ROM UART_DOWNLOAD，TTL 刷机） |
| 22/25 | MICO_GPIO_22 / 手册名"MICO_UART1_RXD" | **PA29** | **日志/下载 UART RX**（TTL 刷机；21≡24、22≡25 为同信号双焊盘） |
| 16 / 17 | VDD33 / GND | — | 3.3V / GND |
| 19 | MICO_GPIO_19（BOOT strap） | PA11 | 上电拉低→下载模式；运行时 MiCO SYS_LED |
| 23 | MICO_GPIO_23（EASYLINK） | PA8 | 配对键（M1 未用） |
| 13 | MICO_GPIO_13 / PWM4 | **PA12** | → TP54（WiFi 图标旁红色叉灯） |
| 14 | MICO_GPIO_14 / PWM5 | **PA5** | → TP53（WiFi 图标灯） |
| 12 | MICO_GPIO_12 / PWM3 | PA0 | （M1 未用） |
| 1/3 | MICO_GPIO_1 / **SWCLK** | PA14 | SWD 时钟 |
| 2/4 | MICO_GPIO_2 / **SWDIO** | PA15 | SWD 数据 |

> 该映射由公开拆解资料、RTL8710B SDK、社区文档与万用表实测交叉验证得出。
> LibreTiny / ESPHome 直接写 `PA23`/`PA18` 等名字即可。
1. **A_D Electronics teardown**：
   EMW3080 内部实为 **MX1290**（MXCHIP 贴牌的 RTL8710BN），文章把两颗芯片的
   QFN-32 引脚图并排给出。同一封装位置互查即得 MICO_GPIO_x ↔ GPIOA_y：
   `GPIO_21→PA30、GPIO_22→PA29、GPIO_23→PA8、GPIO_19→PA11、GPIO_13→PA12、
   GPIO_14→PA5、GPIO_12→PA0、GPIO_9→PA23、GPIO_10→PA18、GPIO_8→PA19、
   GPIO_7→PA22、GPIO_1→PA14、GPIO_2→PA15`。
   （本仓库已放大存档：`docs/mx1290_pin.png`、`docs/rtl8710bn_pin.png`，
   均为 A_D Electronics 拆解文中 MX1290 与 RTL8710BN 的 QFN-32 引脚图。）
2. **RTL8710B SDK**（`framework-realtek-amb1`，`serial_api.c` + `rtl8711b_rcc.h`）：
   UART0: TX=PA23(或PA4)、RX=PA18(或PA1)；UART2=LOGUART=**下载/日志口** PA30/PA29
   （`APBPeriph_LOGUART = BIT_PERI_UART2_EN`）。
3. **esp8266.ru 论坛存档**：进 UART_DOWNLOAD
   要拉低 TX(GPIOA30)；GPIOA11=模块 19 脚(BOOT)；pin21/24=UART_DOWNLOAD；
   LogCLI 在 pin21/22；UART0=模块 9/10 脚。
4. **Ginlong Solis S3 WiFi 棒**（同用 EMW3080，`mi-refs/ginlong-solis/`）：
   ESPHome `uart: tx: PA23, rx: PA18`（走模块 9/10 脚对逆变器 Modbus 通信），
   两只 LED=PA12/PA05（走模块 13/14 脚），PA08=复位按键（模块 23 脚 EASYLINK）——同模块同引脚同用途。
5. **万用表实测**：模块 9/10 ↔ SAMD20 第 32/31 脚（PA23/PA22），模块 11(CHIP_EN) ↔
   SAMD20 第 33 脚（PA24），模块 13/14 ↔ TP54/TP53。

#### 万用表原始记录（蜂鸣档）

| 测量 | 结论 |
|---|---|
| 模块 9 脚 ↔ SAMD20 第 32 脚（48脚封装 PA23） | 模块 TX → SAMD20 RX ✓（PA23） |
| 模块 10 脚 ↔ SAMD20 第 31 脚（PA22） | SAMD20 TX → 模块 RX ✓（PA18） |
| 模块 11 脚 ↔ SAMD20 第 33 脚（PA24） | SAMD20 控制模块 CHIP_EN ✓ |
| 模块 13 脚 ↔ TP54 | = PA12（状态灯候选） |
| 模块 14 脚 ↔ TP53 | = PA5（状态灯候选） |
| 模块 3 脚 ↔ TP15、TP14 | = PA14 = SWCLK（SWD 测试点网） |
| TTL 刷机接模块 16/17/24/25 | = VCC/GND/PA30(TX)/PA29(RX) ✓ |


### 3.2 WiFi 状态灯（已实测确认）

- 模块 **14 脚 = PA5 → TP53 = WiFi 图标灯**
- 模块 **13 脚 = PA12 → TP54 = WiFi 图标旁红色叉灯**

## 4. 开源替代固件路线（EMW3080 = RTL8710B）

1. **平台**：LibreTiny 的 `realtek-ambz`(RTL8710B) 平台，ESPHome 原生支持
   （`rtl87xx` framework）。EMW3080B 一般 2MB flash，满足要求。
2. 注意：LibreTiny **v1.12.x 起 UART0 RX 存在回归**（TX 正常、RX 收不到数据），
   v1.13.0 仍未修复；本固件固定使用 **v1.10.0**。
